## Use it
- **On a computer:** download this folder and open `index.html` in Chrome, Edge or Safari. No installation needed.
- **As an app on a phone:** host the folder on HTTPS (for example GitHub Pages), open it, then
  Android Chrome › menu › *Install app*, or iPhone Safari › Share › *Add to Home Screen*.

## What's inside
- Official GRE and IELTS guidelines, strategy, 60 lessons (incl. the full ETS Math Review)
- 1,045 GRE Quant questions (KMF 74 sections + original), GRE Verbal, IELTS Reading and Listening
- Cambridge IELTS 8 listening tests with original audio
- 1,425 GRE words with pronunciation
- The exact GRE on-screen calculator, timed tests, and mistake review
